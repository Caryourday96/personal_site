# Remote Desk

Canonical URL: https://adeticket-remote-desk.azurewebsites.net/

Private access key required. This dashboard sends tasks to a separate Codex worker on the owner’s PC and shows task progress and account usage. It does not control existing active desktop chats. The PC must remain powered, signed in and online.

Hosted as adeticket-remote-desk on the existing fitness-linux-b1 Azure plan. All eight previous portfolio entries are preserved. Credentials, prompts, responses and usage records are deliberately excluded from this public repository.
